## Steps on How to Create a GitHub Page
1. Used the repository provided by GitHub Classroom.
2. Created `index.html` and `style.css`.
3. Committed and pushed the files to the main branch.
4. Opened Settings and selected Pages.
5. Set the source to main branch and root folder.
6. Waited for GitHub to publish the website.
